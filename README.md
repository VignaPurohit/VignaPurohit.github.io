# Vigna Purohit — GIS Portfolio

A geospatial & data analytics portfolio site built with [Eleventy](https://www.11ty.dev/), deployed on Netlify.

## Structure

- `content/` — page templates (`index`, `education`, `experience`, `projects`), written as Nunjucks (`.njk`) so the custom mockup-matched layout renders exactly, without markdown-it reinterpreting the hand-built HTML.
- `src/_includes/` — shared layout (`base.njk`) and the social-icons partial.
- `src/_data/site.js` — site-wide data: nav links, name, email, social URLs.
- `src/css/style.css` — hand-written stylesheet; design tokens (colors, spacing) at the top of the file match the approved home-page mockup.
- `src/assets/images/` — processed photos (WebP + JPEG), generated by `scripts/build-images.js` from the originals in `../portfolio_material/`.
- `src/assets/notebooks/` — the two Jupyter notebooks linked from the Projects page.
- `src/assets/Vigna-CV.pdf` — CV, linked from the Experience page.

## Local development

```bash
npm install
npm run serve     # http://localhost:8080, live reload
npm run build      # outputs to _site/
```

## Regenerating images

Source photos live outside this repo, in `../portfolio_material/`. To re-crop or re-export them:

```bash
npm run images
```

This re-runs `scripts/build-images.js`, which crops the hero collage photos and the hero background band, resizes the workshop gallery, and copies the CV + notebooks into `src/assets/`.

## Deployment

Configured for Netlify via `netlify.toml` (`npm run build` → publish `_site`). Connect this GitHub repo in the Netlify dashboard to enable auto-deploys on every push to `main`.
